# Format aturan di guru/preferensi.md

Satu aturan = satu blok. Nomor terus bertambah dan tidak dipakai ulang.

```
## Aturan #001 — 2026-10-15
Cakupan : dokumen: ATP · mapel: semua
Aturan  : Tambahkan kolom "Integrasi nilai Islam" berisi konteks dan kegiatan, tanpa dalil.
Status  : aktif            # aktif | diganti | dibatalkan
```

- Satu aturan memuat satu hal. Pisahkan jika guru memberi dua arahan.
- Tulis sebagai kalimat perintah yang jelas dan bisa diperiksa.
- Cakupan sesempit yang dimaksud guru.
- Jangan menyimpan data pribadi siswa.

Format `guru/riwayat-perubahan.md` (satu baris per kejadian):
```
2026-10-15 | #001 | ditambahkan | ATP, semua mapel
```
