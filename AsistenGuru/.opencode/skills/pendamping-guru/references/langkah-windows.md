# Langkah di Windows (untuk dituntunkan satu per satu)

Sampaikan satu bagian saja, lalu tanya "Sudah, Bu?". Nama tombol bisa sedikit berbeda di Windows 10/11.

## Membuka folder Asisten Guru
1. Klik ikon map kuning (File Explorer) di bawah layar, atau tekan tombol Windows + E bersamaan.
2. Di kiri, klik **Documents** (atau **Dokumen**).
3. Klik dua kali folder **AsistenGuru**.

## Menaruh berkas dari sekolah di folder masukan
1. Buka folder AsistenGuru (lihat di atas), lalu klik dua kali **guru**, lalu **masukan**.
2. Buka jendela lain tempat berkas sekolah berada (misalnya folder **Downloads**, atau flashdisk).
3. Klik kanan berkasnya › **Salin** (Copy).
4. Kembali ke folder **masukan**, klik kanan di ruang kosong › **Tempel** (Paste).
5. Bilang "sudah" ke asisten.
- Berkas dari WhatsApp: buka WhatsApp di laptop, klik berkasnya › Unduh, lalu ikuti langkah di atas dari folder Downloads.

## Membuka hasil Word/Excel
1. Buka folder AsistenGuru › **hasil**.
2. Pilih foldernya: 1 Perencanaan, 2 Modul dan LKPD, 3 Asesmen, 4 Administrasi, 5 Kokurikuler, 6 Dokumen Sekolah.
3. Klik dua kali berkasnya; akan terbuka di Word atau Excel.

## Mengisi Excel (nilai, daftar hadir)
1. Buka berkasnya (lihat di atas). Jika muncul tombol kuning **Enable Editing / Aktifkan Pengeditan**, klik tombol itu.
2. Isi hanya kotak berwarna kuning/putih yang disediakan. Kolom lain terhitung sendiri.
3. Simpan: tekan **Ctrl + S**, lalu tutup Excel.

## Mencetak
1. Buka berkasnya, tekan **Ctrl + P**.
2. Pilih printer, lalu klik **Print/Cetak**. Untuk menyimpan sebagai PDF, pilih printer "Microsoft Print to PDF".

## Jika asisten diam lama
Tekan **Esc**, lalu ketik ulang pesan terakhir. Jika masih diam, tutup OpenCode lalu buka lagi.
