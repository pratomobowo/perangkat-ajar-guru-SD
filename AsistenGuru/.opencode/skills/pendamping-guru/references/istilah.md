# Istilah dalam bahasa awam

Pakai penjelasan singkat ini saat istilah pertama kali muncul dalam percakapan.

| Istilah | Jelaskan sebagai |
|---|---|
| CP (Capaian Pembelajaran) | Target kemampuan dari pemerintah untuk satu fase (2 tahun), misalnya kelas 3–4. Semua tujuan belajar diturunkan dari sini. |
| Fase A / B / C | Kelompok kelas: A = kelas 1–2, B = kelas 3–4, C = kelas 5–6. |
| TP (Tujuan Pembelajaran) | Satu target kecil yang dicapai murid dalam beberapa pertemuan, misalnya "menentukan pecahan senilai". |
| ATP (Alur Tujuan Pembelajaran) | Daftar TP setahun yang sudah diurutkan dari yang paling dasar. |
| Prota | Program tahunan: TP apa diajarkan di semester berapa, berapa jam pelajarannya. |
| Promes | Program semester: TP apa diajarkan di minggu ke berapa. |
| Minggu efektif | Minggu yang benar-benar dipakai belajar (di luar libur dan kegiatan sekolah). |
| JP (Jam Pelajaran) | Satu jam pelajaran, di SD biasanya 35 menit. |
| Modul Ajar / RPM / RPP | Rencana mengajar untuk satu TP: tujuan, langkah kegiatan per pertemuan, dan penilaiannya. Namanya mengikuti istilah sekolah. |
| LKPD | Lembar kerja murid yang difotokopi. |
| KKTP | Patokan kapan murid dianggap sudah mencapai TP ("memenuhi") dan nilai minimalnya. |
| Asesmen formatif | Penilaian selama belajar, untuk tahu siapa yang perlu dibantu (kuis, LKPD, pengamatan). |
| Asesmen sumatif, STS, SAS | Penilaian di akhir: STS = tengah semester, SAS = akhir semester. |
| Remedial / pengayaan | Belajar ulang untuk yang belum tuntas / tantangan tambahan untuk yang sudah tuntas. |
| Kokurikuler | Kegiatan belajar lintas mapel (pengganti P5), dinilai per dimensi profil lulusan. |
| Dimensi profil lulusan | 8 karakter yang dikembangkan: keimanan, kewargaan, penalaran kritis, kreativitas, kolaborasi, kemandirian, kesehatan, komunikasi. |
| Deskripsi rapor | Kalimat di rapor tentang kemampuan yang sudah dikuasai dan yang perlu ditingkatkan. |
| Dapodik / e-Rapor | Aplikasi data sekolah dan aplikasi rapor dari Kemendikdasmen (diurus operator sekolah). |
| Folder masukan | Tempat menaruh berkas dari sekolah supaya dibaca asisten: Documents › AsistenGuru › guru › masukan. |

## Pesan GAGAL → langkah untuk guru

| Isi pesan alat | Sampaikan sebagai |
|---|---|
| CP belum tersedia | "Target pemerintah untuk mapel ini belum ada. Mau saya ambilkan yang resmi? (butuh internet)" |
| Data ATP … belum ada | "Daftar tujuan belajar setahun belum disusun. Saya susunkan dulu ya (sekitar 2 menit)?" |
| Kalender … / tidak ada hari sekolah | "Saya belum tahu tanggal semester dan libur. Ibu punya kalender dari sekolah? Kalau tidak, sebutkan tanggal awal semester saja dulu." |
| tidak berisi teks (pindaian/foto) | "Berkas itu berupa gambar/foto, jadi tidak bisa saya baca. Ada versi Word/Excel-nya? Kalau tidak, Ibu bisa ketik poin pentingnya di sini." |
| berformat lama (.doc/.xls) | "Berkas itu format lama. Buka di Word/Excel, lalu File › Simpan Sebagai › pilih .docx/.xlsx, dan taruh lagi." |
| tanpa internet / unduhan gagal | "Internetnya sepertinya terputus. Coba sambungkan Wi-Fi lalu bilang 'coba lagi'." |
| Daftar Siswa belum ada | "Nama siswa belum ada, jadi kolom nama masih kosong. Kalau ada daftar dari Dapodik/e-Rapor atau absen lama, taruh di folder masukan." |
